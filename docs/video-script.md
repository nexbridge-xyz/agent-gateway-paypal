# Video script: Agent Gateway for PayPal

Final cut: 2:39 (limit: under 3:00). Video: https://youtu.be/ZOB1QYYq0zg

- **Footage:** one screen recording made on 2026-11-11 in live mode: the PayPal sandbox, with Claude Sonnet 5.5 as the agent. Nothing in the app is simulated in this recording.
- **Voice-over:** AI-generated (Kokoro TTS). The narrator speaks as the traveler. No music.
- **Captions:** English subtitles are uploaded with the video.
- **Editing:** waiting time is sped up; no result that the voice-over describes is cut. A caption bar covers the browser's tab strip and address bar. The card brand on PayPal's consent page is blurred (third-party mark). The operating system's save dialog is cut.
